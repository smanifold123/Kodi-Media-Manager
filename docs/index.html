Kodi Media Manager

A lightweight tool to manage, organize, and maintain media libraries for Kodi.

This page provides a quick overview, installation steps, and usage examples for Kodi Media Manager hosted at: github.com/smanifold123/Kodi-Media-Manager .

Overview

Kodi Media Manager is designed to help you keep your Kodi media library clean, consistent, and well-structured. It focuses on:

  • Scanning media folders and identifying missing or inconsistent metadata.
  • Generating or updating NFO files and artwork where applicable.
  • Providing a repeatable workflow for maintaining large media collections.

Features

  • Library scan: Scan specified directories for movies/TV shows.
  • Metadata checks: Detect missing NFO files or artwork.
  • Batch operations: Apply changes across multiple items at once.
  • Config-driven: Use a simple configuration file to define paths and options.

Requirements

  • Operating system: Windows 10 or later (recommended).
  • Kodi: Existing Kodi installation with media library folders.
  • Dependencies: (Adjust this list to match the repo)
    • Python 3.x / .NET / PowerShell (whichever your tool uses).
    • Access to your media folders (read/write).

Installation

  1. Clone or download:
    Use Git to clone the repository:
    git clone https://github.com/smanifold123/Kodi-Media-Manager.git

    Or download the ZIP from the GitHub page and extract it.
  2. Place files:
    Extract or clone to a convenient location, e.g. C:\Tools\Kodi-Media-Manager.
  3. Install dependencies:
    Follow the instructions in the repository’s README.md for any required libraries or runtime (e.g. Python packages, .NET runtime).

Usage

The exact usage depends on how the tool is implemented in the repository. Adjust the examples below to match your actual script or executable names.

Basic command-line usage

Example (PowerShell / Command Prompt):


cd C:\Tools\Kodi-Media-Manager

# Example: run main script
KodiMediaManager.exe

# Or, if Python-based:
python kodi_media_manager.py --config config.json

Typical workflow:

  • Step 1: Configure media paths and options in the config file.
  • Step 2: Run the tool to scan your library.
  • Step 3: Review output/logs for missing metadata or issues.
  • Step 4: Re-run as needed after adding new media.

Configuration

Kodi Media Manager typically uses a configuration file (e.g. config.json or settings.ini) to define:

  • Media root paths: Where your movies and TV shows are stored.
  • Output options: Whether to create/update NFO files, artwork, etc.
  • Logging: Log file location and verbosity.

Example JSON snippet (adjust to match your actual format):


{
  "movie_path": "D:\\Media\\Movies",
  "tv_path": "D:\\Media\\TV",
  "create_nfo": true,
  "update_artwork": true,
  "log_file": "logs\\kodi_media_manager.log"
}
