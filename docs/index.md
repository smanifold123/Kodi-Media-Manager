# Kodi Media Manager

A lightweight tool for managing and maintaining Kodi media libraries.

---

## 📥 Download

Latest release:

[**Download from GitHub Releases**](https://github.com/smanifold123/Kodi-Media-Manager/releases/latest)

---

## 📘 Overview

Kodi Media Manager helps you:

- Scan media folders
- Detect missing metadata
- Generate or update NFO files
- Maintain artwork consistency
- Automate repetitive library maintenance tasks
